# HappyBull RAG 源码｜学习计划

## 学习目标

完成本课题后，可以独立做到以下几件事：

1. 从 HTTP 入口沿着调用链找到文档解析、分块、向量化和索引写入代码。
2. 解释 Block、Parent Chunk、Child Chunk 三层数据各自解决的问题。
3. 手算一次向量召回、BM25、加权融合和 Rerank 的排序过程。
4. 说明知识库检索如何成为 Agent 工具，以及回答中的引用从哪里产生。
5. 使用项目自带的检索验证页、测试和评测集定位召回问题。

## 学习路径

1. 建立全局地图：认识入库链、检索链、Agent 接入点和数据落点。
2. 深入入库链：解析器路由、Block 结构、父子分块、向量写入。
3. 深入检索链：KNN、BM25、归一化、融合、Rerank、父块回填。
4. 深入问答链：工具启停、知识库范围、模型调用、引用收集。
5. 学会验证：检索验证页、单元测试、离线评测及常见问题定位。
