# 反思引擎（Insight）

反思引擎从高重要度、高频实体和代表性陈述中归纳高层洞察，例如长期偏好、稳定目标或行为模式。Insight 写入 Neo4j，并可向量化参与对话召回。

## 触发方式

- 用户在记忆页手动触发。
- 新增记忆达到 `reflection_trigger_threshold` 时，由写入链路向 `memory` 队列投递反思任务。

Echo 不使用 Celery Beat，反思不依赖定时调度。

## 数据流

```mermaid
flowchart LR
  E[Top 实体] --> S[代表性 Statement]
  S --> L[LLM 归纳 Insight]
  L --> V[可选向量化]
  V --> N[(Neo4j Insight)]
  N --> R[对话主动召回]
```

相同主题使用 upsert 更新，不无限追加近义洞察；原子记忆不被反思覆盖或删除。

面试问答：

**Q：反思和普通记忆有什么区别？**

A：普通记忆保存原子事实和事件，反思将多个事实归纳成更高层理解。回答时可以同时召回具体证据和概括性 Insight。

**Q：为什么要设置新增阈值？**

A：每次写入都反思会产生高模型成本和近义重复。阈值触发把多次小更新合并成一次归纳。
