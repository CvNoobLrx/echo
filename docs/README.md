# Echo 设计与面试资料

本目录只保留 Echo 当前真实能力对应的设计与面试材料。

## 能力域

- `00-总览与面试开场`：项目介绍、能力地图和简历表达。
- `01-LLM应用工程`：模型抽象、SSE、密钥加密和连接管理。
- `02-RAG知识库`：解析、父子分块、IK、混合检索、Rerank、引用和多知识库。
- `03-Agent核心`：Function Calling / ReAct 双路径、工具注册和 MCP。
- `04-记忆`：三元组萃取、图混合检索、反思、主动召回、纠错和 Graph-RAG。
- `06-工程化与部署`：JWT、安全隔离、Celery Worker、Docker 和部署踩坑。
- `08-评测体系`：RAG 与多跳问答评测。
- `99-面试速记`：高频问答速查。

已删除模块的历史设计文档不再保留，避免面试材料与当前代码不一致。`docs/comet` 是开发 workflow 元数据，不是产品功能文档。
