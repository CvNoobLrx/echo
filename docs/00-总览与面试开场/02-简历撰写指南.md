# Echo 简历撰写指南

项目描述建议只写当前代码已经具备的能力：

> Echo 是一个面向个人知识管理的 AI 助手，支持多知识库、多模态资料入库、Graph Memory、Agent 工具编排和 Docker 部署。后端使用 FastAPI 分层架构，数据在 PostgreSQL、Elasticsearch、Neo4j、Redis 中按 user_id 隔离。

可选项目要点：

- 设计父子块 RAG 流水线，使用 IK、向量召回、BM25、RRF 和可选 Reranker，在召回粒度与回答上下文之间解耦。
- 构建对话记忆萃取链路，将实体、关系、事件及溯源节点异步写入 Neo4j，并提供主动召回、反思洞察和人工纠错闭环。
- 基于 LangChain 实现 Function Calling / ReAct 双路径 Agent，统一接入知识库、记忆、联网搜索与 MCP 工具，并通过 SSE 输出执行过程和回答。
- 使用 JWT、Fernet 和 user_id 强制过滤实现多账号私有隔离；通过 Celery 将解析、图片处理和记忆萃取移出请求线程。
- 使用 Docker Compose 编排四存储、API、Worker 和 Web，并为开发与生产提供独立资源配置。
