# Echo 能力地图与 JD 对照

| 能力域 | Echo 实现 | 可回答的面试主题 |
|---|---|---|
| LLM 应用 | 多 Provider、密钥加密、SSE、Function Calling / ReAct | 模型抽象、流式协议、降级策略 |
| RAG | 父子块、IK、向量 + BM25、RRF、可选 Rerank | 分块、混合检索、过滤与引用 |
| Agent | 工具注册、知识/记忆/联网路由、MCP | 工具协议、权限、错误恢复 |
| 记忆 | 三元组、事件、Neo4j、反思、主动召回、纠错 | 图谱建模、去重、可靠性与溯源 |
| 工程化 | JWT、Fernet、user_id 隔离、Celery Worker | 安全、异步任务、幂等和水平扩展 |
| 部署 | PostgreSQL、ES、Neo4j、Redis + API/Worker/Web | Compose、健康检查、资源约束 |
| 评测 | RAG 单测、自制集、公开基准脚本 | Recall、MRR、nDCG、多跳问答 |
